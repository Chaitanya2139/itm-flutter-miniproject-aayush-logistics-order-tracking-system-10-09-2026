# Aayush Logistics & Order Tracking System

A comprehensive logistics platform where clients book transport orders for goods, admin verifies orders and payments (via call), and generates unique LR numbers for tracking. Clients can track orders in real-time with map-based location display, and admin can attach delivery documents (bills, receipts, PDFs) after order completion.

## Key Focus Areas
- Order booking & payment verification
- Unique LR number generation & tracking
- Real-time location tracking with maps
- Document attachment system
- Admin & client dashboards

## Tech Stack
- Flutter
- Real-time Geolocation
